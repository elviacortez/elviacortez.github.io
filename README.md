## 📂 Estructura del Repositorio

El repositorio está organizado para separar la documentación teórica de los desarrollos prácticos:

* **/assets y /images:** Recursos gráficos, estilos e imágenes utilizadas para el diseño de la interfaz web y la visualización de datos.
* **Cuadernos de la Especialización (IBM):** Recopilación de Jupyter Notebooks desarrollados a lo largo de los cursos de la especialización, cubriendo desde análisis exploratorio hasta modelado predictivo.
* **Proyectos de Datos (Submenú):** Sección dedicada a proyectos aplicados donde integramos la limpieza de datos, machine learning y storytelling analítico.

## 🚀 Proyectos Destacados

### 1. Segmentación de Clientes con K-Means (Machine Learning No Supervisado)
* **Descripción:** Análisis de comportamiento financiero de clientes para optimizar campañas de marketing y retención.
* **Técnicas aplicadas:** Limpieza de datos, estandarización (`StandardScaler`), clustering con K-Means, interpretación de centroides, visualización avanzada en 2D (con dimensiones múltiples mediante burbujas) y exportación de segmentos orientados a CRM.
* **Archivos clave:** Disponible en la sección de proyectos de datos.

### 2. Análisis de Sismos 
* **Descripción:** Procesamiento y visualización geoespacial/estadística de datos sísmicos para la identificación de patrones.
* **Archivos clave:** Disponible en la sección de proyectos de datos.
